# Aprenda a Programar em C# com OOP
Projetos feitos em uma das formações CSharp da Alura, com objetivo de estudo.

## Tecnologias utilizadas
* CSharp

## Projetos
O repositório contém 4 projetos:
- Aula 1: ```C# - Criando sua Primeira Aplicação```
- Aula 2: ```C# - Aplicando a Orientação a Objetos```
- Aula 3: ```C# - Dominando a Orientação a Objetos```
- Aula 4: ```C# - Consumindo API Gravando Arquivos e Utilizando o LINQ```

## Como Usar
Clone o repositório no bash: ```git clone https://github.com/Rafael-RRB/csharp-01.git```
